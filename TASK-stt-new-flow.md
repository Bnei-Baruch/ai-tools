# Задача: страница `/stt` (תמלול) на новый flow — говорящие и абзацы

Поставлено: 2026-11-05 (решено с пользователем).

## Сейчас
- `/stt` (`src/pages/Stt.tsx`): ссылка → задача ai-trns (`api/transcribe.ts`, `format=srt`) → куски SRT рядом с плеером,
  пометка проблемных кусков + копирование, выгрузка SRT. Говорящих и абзацев нет; «не закрывайте страницу».
- Новый flow есть только в `/compare` (вид «говорящие»): `api/speakers.ts` `speakerParagraphs()` — задача
  `/diarize/words` с `paragraphs=true` и источником урока (`api/kmedia.ts` `fetchLessonSource`: LIKUTIM из `derived_units`,
  ивритский .docx) → абзацы с метками רב / קריין / תלמיד и временем каждого слова.

## Что сделать
1. **Вход**: ссылка на урок kabbalahmedia (`…/lessons/cu/<uid>`), просто uid, или прямая ссылка на медиа (как сейчас).
   По uid — аудио/видео сами (`pickFiles`), источник — `fetchLessonSource` (позже сервер будет находить его по uid сам —
   см. ai-trns `TASK-speakers-paragraphs.md`; сделать так, чтобы переключить было одной правкой в `api/speakers.ts`).
   Прямая ссылка без uid → без источника (чтец по голосу/фразам «קטע מספר»), сказать это в интерфейсе.
2. **Поэтапно**: текст показывать сразу после распознавания (как сейчас куски), затем запускать говорящих+абзацы
   и заменять вид на абзацы, когда готово. Состояние этапов видно (распознавание → говорящие и абзацы), с временем.
   Если второй этап упал — остаётся текст распознавания и понятная ошибка.
3. **Вид текста**: абзацы с меткой говорящего (רב / קריין / תלמיד, разные цвета/отступ); чтение источника (קריין) —
   бледнее и сворачиваемо; клик по слову → перемотка; текущее слово/абзац подсвечены, автопрокрутка (не мешать, если
   человек прокрутил сам). Пометка проблемных мест + копирование — сохранить (на уровне абзаца или выделения).
4. **Выгрузка**: SRT с говорящими (сервер уже умеет: `/diarize/words/srt` в `api/tools.js`), .txt и .docx абзацами
   с метками говорящих.
5. **Можно закрыть страницу**: id задач (и uid/ссылка) — в адресе (`/stt/<jobId>` или query); при открытии адреса
   результат подтягивается с сервера / ожидание продолжается. Убрать «אל תסגרו את הדף».
6. Переиспользовать компоненты `/compare` (`TextColumn`, разбор абзацев), не копировать.

## Критерии
- `yarn build` и тесты зелёные; новые тесты на разбор входа (uid/ссылка) и на выгрузку .txt/SRT.
- Проверить вживую на 1–2 уроках (короткая часть), скриншот.
- Интерфейс на иврите, RTL, как остальные страницы.

- Не мержить в master и не деплоить — ветка `feature/stt-new-flow`, PR на проверку пользователю.
